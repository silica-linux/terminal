# Menus

Session TE-01. Menu titles: app menu, Shell, Edit, View, Window, Help.

| Menu | Items worth matching |
| --- | --- |
| Shell | New Window ⌘N and New Tab ⌘T, each with a submenu listing every profile (the plain shortcut uses the default profile); show inspector ⌘I; edit title ⇧⌘I; edit background colour ⌥⌘I |
| Edit | marks and bookmarks at prompts, with ⌘↑ / ⌘↓ to jump between them; clear to start ⌘K; Find ⌘F, find next ⌘G, find previous ⇧⌘G; use Option as Meta ⌥⌘O |
| View | show all tabs; show / hide the tab bar ⇧⌘T; split ⌘D (close split ⇧⌘D); font size ⌘0 / ⌘+ / ⌘− |
| Window | the system tiling items; previous / next tab ⌃⇧⇥ / ⌃⇥; merge all windows; window groups; the window list with ⌥⌘1 … |

The shortcut for "show all tabs" depends on the keyboard layout (it was read on an Italian
layout) and is not given here.
