# Inspector (⌘I)

Session TE-01, light only. Viewed, nothing edited.

- A floating panel **281 × 564** with two tabs: information and profile.
- The information tab has, top to bottom:
  - title: a field for the window title and one for the tab title;
  - window: columns (80) and rows (24) fields, and a background colour well;
  - locations: current directory and represented document;
  - login: the terminal device, the command, the shell and the start-up script;
  - running processes: a table with kind, process name and process id.
- The profile tab: *unmeasured*.
- Field heights, fonts and spacing: *unmeasured*.
